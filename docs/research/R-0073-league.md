## Recovered routines and state

The six ONE-SIX entries are saved league slots, each with two to eight humans.
Membership `$77:02B4` is a bit mask in reverse rider-ID order. Census-order played/points are interleaved 16-bit words from `$77:02C0`, 32 bytes per slot. Pairing rank is a separate eight-byte list from `$77:05E8`. Event totals start at `$77:0618`, 16 bytes per slot; cursor bytes at `$77:0678`, track bytes at `$77:067E`, interleaved bonus/holder words from `$77:0684` (four bytes per slot). Unused pairing IDs are 16. Cold unused bonus words are zero, not a no-time sentinel.

- `$83:963C-967B` enumerates membership. `$80:AD47-ADE2` reorders saved pairings. `$80:EFD4-F02A` moves the lowest value to the end, replacing the selection on equality. Its initial comparison limit is 0x7FFF; native retains that exact unsigned behavior. `$80:A5B2-A65E` prints competition ranks, with a skipped ordinal after a tie. `$80:A68D` is the standings text. Census statistics stay attached to census IDs while pairing rank changes.
- `$83:958C` starts the lower rider ID on port 1, and `$83:95CA` restores persistent pairing order for totals, laps, scores and tallies. `$80:F88D` stores event totals. `$80:AF54` increments each valid human's played word, wraps at 16 bits and advances the pair cursor by two. The odd CPU participates in the race but takes no award place.
- `$80:8B3F-8B6C` prints the bonus holder. The eight places receive 10, 8, 7, 6, 5, 4, 3 and 2 points, plus one to the holder; additions wrap at 16 bits. `$80:D3F5` initializes the defining editor's bonus to zero. Reordering initializes the next bonus from the old track position: no-time for positions 0/3, zero otherwise. Best laps replace only on a strict improvement; stunt wipeout ties replace with the later valid human. Ordinary trick bonus compares sums of wrapping byte counts.
- `$80:9E3C-9E54` writes the last membership marker's column and row into the scratch that the league name editor preserves. The strict odd-resume projection exposes SRAM `$77:0172` as 0x13 (CRAIG's row), while the earlier hardcoded two-member suffix used 0x0D (COLIN's row); the checksum at `$77:022E` differed by six. Native now carries the marker position rather than changing the expected bytes.
- `$83:9F30` and the existing editor reset clear census statistics on membership confirmation. Pairing and track continuation are initialized at that confirmation, before the name editor. The task preserves the existing name editor and its original stale-tail behavior.
- `$81:8AFB-8B03` uses each viewport's own start origin for BG2 displacement. The original BOWL STUNT retained frames 19300/21000 establish two active human views, shared countdown and independent score/tally paths. `$83:E8F0` and `$83:EA82` dim the completed view using its brightness word; the main fade word can still read 30.
