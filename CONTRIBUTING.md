# Contribution policy

This repository is public so people can follow development and explore the
research. External contributions and pull requests are not being accepted at
this stage. These guidelines will be updated when that changes.

Pull requests are restricted to repository collaborators so the existing internal
review and CI workflow can continue. Issues remain available for feedback, but
there is no commitment to implement requests or provide support.

Do not attach ROMs, extracted game assets, or save states to issues or other
public discussions.

Maintainers and authorized agents should start with [AGENTS.md](AGENTS.md) and
follow the existing [development workflow](docs/AGENT_WORKFLOW.md).
